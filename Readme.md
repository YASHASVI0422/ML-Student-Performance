# 🎓 Student Performance Prediction - Intel Unnati CIA

This project is part of the Intel Unnati CIA module. It aims to predict student performance using machine learning techniques based on the `student-mat.csv` dataset.

## 📊 Overview

Using features like family background, education, and personal habits, the model classifies students into:
- **1** → Good Performance (Final Grade > 10)
- **0** → Poor Performance (Final Grade ≤ 10)

- Evaluation:

  - Confusion Matrix
